## 二、为什么采集模块不开源

三个原因：

```
① 平台条款
   抖音、小红书都明确禁止用技术手段模拟真人操作。
   采集代码公开，等于教人违规，平台方可以据此举报仓库。

② 责任边界
   采集行为在别人机器上跑，出问题（账号被封）无法控制。
   不公开能把责任边界说清楚。

③ 维护成本
   采集依赖平台页面结构，改版就要修选择器。
   公开之后会有大量"跑不起来"的问题找上门。
```

对应地，README 末尾有免责声明，明确了使用边界。

## 三、开源版能做什么

clone 下来直接能跑：

```
✅ 登录管理端（admin / 123456）
✅ 手工录入线索、Excel 导入
✅ 线索打分分级（S/A/B/C/D）
✅ 转客户、跟进记录、成交阶段
✅ 配置大模型，生成开场话术
✅ 知识库上传、检索测试
✅ 报表、跟进提醒
✅ 微信消息监听（需要本机登录微信）
✅ 数据全部在自己电脑
```

## 四、开源版缺什么，影响是什么

```
缺采集模块
  影响：没有自动进线索的能力
  替代：Excel 导入，或自己写采集脚本
       后台有 createLead 接口，任何语言都能对接

缺运行时配置
  影响：第一次启动要自己建 config.yaml 和 llm.json
  替代：仓库里有 config.example.yaml 和 docs/db.example.json

缺客户数据
  影响：没有任何示例数据
  替代：可以自己导入，或用演示数据脚本（未开源）
```

## 五、完整版说明

如果确实需要自动采集，完整版包含开源版的全部内容，加上：

```
抖音采集     关键词搜视频、抓评论、抓账号，带城市/时间过滤
小红书采集   关键词搜笔记、抓评论（必须从搜索结果进入，规避 xsec_token 问题）
私信监听     抖音 / 小红书收件箱轮询，白名单内 AI 自动回复
主动私信     白名单内从对方主页发起对话
反检测       浏览器指纹伪装、行为随机化、每日配额
账号隔离     每个平台独立浏览器 profile + 独立调试端口
```

### 运行环境要求

```
系统      Windows 10 / 11（采集依赖桌面客户端，不能跑在无桌面的服务器）
数据库    MySQL 8.0
后端      Go 1.22+
前端      Node 20+ / pnpm
语音      Python 3.11（微信语音转文字，可选）
浏览器    Microsoft Edge（采集用独立 profile）
客户端    微信 PC 版（需登录）、抖音 / 小红书网页版（需登录）
```

### 部署步骤（概览）

```
① 装 MySQL，建库 ai_go，导入 sql/schema.sql
② 改 config.yaml 填数据库密码，建 llm.json 填大模型 Key
③ go build 出 gva.exe，启动（前端已打包进二进制）
④ 登录管理端，创建菜单和账号
⑤ 装 Node / Python，配置采集脚本目录
⑥ 首次登录抖音 / 小红书网页版（扫码），保存登录态
⑦ 启动采集和监听
```

### 维护成本

```
平台改版          选择器可能要改，平均 1–3 个月一次
微信掉登录        需人工扫码，程序只能告警
账号被限流        需要降频或换号，属于平台风控范畴
```

## 七、如果你想自己实现采集

不一定要完整版。后台已经有对接接口，任何语言都能推数据进去：

```
POST /lead/createLead
  {
    "company": "某某商行",
    "contactName": "张姐",
    "phone": "138...",
    "source": "douyin",
    "side": "buyer",
    "content": "鸡蛋怎么批发"
  }
```

需要带 `x-token`（登录接口获取）。

你用自己的方式拿到线索（人工整理、第三方工具、Excel），推到这个接口，后面的打分、分级、AI 接待、跟进都照常工作。
