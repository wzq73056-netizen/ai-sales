## 二、采集代码为什么可以公开

平台签名算法、登录态、密钥这些“绕过校验”的东西不在仓库里；
仓库里是**操作流程**：打开页面、滚动、抽取、入库。

这和 [TikTokDownloader](https://github.com/JoeanAmier/TikTokDownloader)（17.5k star）的做法一致：
框架公开，平台侧最敏感的实现（签名算法）交给你自己准备。

本项目需要你自己准备的只有一件事：**浏览器登录态**（扫码登录一次，存在本地）。

## 三、开源版能做什么

clone 下来、按文档配置后能跑：

```
✅ 登录管理端（admin / 123456）
✅ 手工录入线索、Excel 导入导出
✅ 线索打分分级（S/A/B/C/D）
✅ 转客户、跟进记录、成交阶段
✅ 配置大模型，生成开场话术
✅ 知识库上传、检索测试
✅ 报表、跟进提醒
✅ 抖音 / 小红书采集（需要自己扫码登录）
✅ 私信监听与 AI 自动回复（白名单机制）
✅ 本机客户端监听（需要自己配环境变量）
✅ 数据全部在自己电脑
```

## 四、仓库里没有的东西

```
✗ 运行时配置      config.yaml / llm.json / db.json（提供模板）
✗ 浏览器登录态    需要自己扫码登录一次
✗ 大模型 API Key  自己申请
✗ 客户数据        一条都没有
✗ 演示数据        自己造或从空开始
```

**这不影响功能完整性**，只是把“凭据”和“数据”交给使用者自己准备。

## 五、完整版说明

如果确实需要自动采集，完整版包含开源版的全部内容，加上：

```
抖音采集     关键词搜视频、抓评论、抓账号，带城市/时间过滤
小红书采集   关键词搜笔记、抓评论（必须从搜索结果进入，规避 xsec_token 问题）
私信监听     抖音 / 小红书收件箱轮询，白名单内 AI 自动回复
主动私信     白名单内从对方主页发起对话
反检测       浏览器指纹伪装、行为随机化、每日配额
账号隔离     每个平台独立浏览器 profile + 独立调试端口
```

### 运行环境要求

```
系统      Windows 10 / 11（采集依赖桌面客户端，不能跑在无桌面的服务器）
数据库    MySQL 8.0
后端      Go 1.22+
前端      Node 20+ / pnpm
语音      Python 3.11（微信语音转文字，可选）
浏览器    Microsoft Edge（采集用独立 profile）
客户端    微信 PC 版（需登录）、抖音 / 小红书网页版（需登录）
```

### 部署步骤（概览）

```
① 装 MySQL，建库 ai_go，导入 sql/schema.sql
② 改 config.yaml 填数据库密码，建 llm.json 填大模型 Key
③ go build 出 gva.exe，启动（前端已打包进二进制）
④ 登录管理端，创建菜单和账号
⑤ 装 Node / Python，配置采集脚本目录
⑥ 首次登录抖音 / 小红书网页版（扫码），保存登录态
⑦ 启动采集和监听
```

### 维护成本

```
平台改版          选择器可能要改，平均 1–3 个月一次
客户端掉登录      需人工重新登录，程序只能告警
账号被限流        需要降频或换号，属于平台风控范畴
```

### 本机客户端监听的环境变量

`scripts/client_watch.py` 需要两个环境变量才能运行：

```powershell
$env:CLIENT_DATA_ROOT = '客户端数据目录（db_storage）'
$env:CLIENT_SKILL_DIR  = '依赖脚本目录（vendor/client-live/scripts）'
```

不设置会直接报错。目录只读，脚本不会修改客户端文件。以普通用户权限运行，
不要用管理员权限（读不到当前用户的密钥）。

## 七、如果你想自己实现采集

不一定要完整版。后台已经有对接接口，任何语言都能推数据进去：

```
POST /lead/createLead
  {
    "company": "某某商行",
    "contactName": "张姐",
    "phone": "138...",
    "source": "douyin",
    "side": "buyer",
    "content": "鸡蛋怎么批发"
  }
```

需要带 `x-token`（登录接口获取）。

你用自己的方式拿到线索（人工整理、第三方工具、Excel），推到这个接口，后面的打分、分级、AI 接待、跟进都照常工作。
